# Images des Accessoires Connectés FitPro

Ce dossier doit contenir les 3 images suivantes pour les accessoires connectés de la boutique :

## Images requises :

1. **gourde_connectee_fitpro.png**
   - Gourde connectée FitPro
   - Dimensions recommandées : 800x800px ou plus
   - Format : PNG avec fond transparent ou fond blanc

2. **assiette_connectee_fitpro.png**
   - Assiette connectée FitPro avec balance intégrée
   - Dimensions recommandées : 800x800px ou plus
   - Format : PNG avec fond transparent ou fond blanc

3. **tapis_compteur_mouvements_fitpro.png**
   - Tapis compteur de mouvements connecté FitPro
   - Dimensions recommandées : 800x800px ou plus
   - Format : PNG avec fond transparent ou fond blanc

## Emplacement des fichiers :

Les images doivent être placées dans : `assets/images/`

Les noms de fichiers doivent correspondre exactement aux noms ci-dessus.

## Note :

Si les images ne sont pas disponibles, l'application affichera automatiquement les emojis de remplacement :
- 💧 pour la gourde
- 🍽️ pour l'assiette
- 🏋️ pour le tapis
