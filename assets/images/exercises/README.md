# Images et Vidéos pour les Exercices

Ce dossier contient les images et vidéos pour les exercices affichés dans l'onglet "Séances".

## Images nécessaires

### Pour les étapes de séance (WorkoutStep)
- `warmup.jpg` - Image pour l'échauffement
- `squats.jpg` - Image pour les squats et fentes
- `pushups.jpg` - Image pour les pompes et exercices du haut du corps
- `stretch.jpg` - Image pour les étirements et retour au calme

### Pour les séances complètes (Workout)
- `beginner.jpg` - Image pour le programme débutant
- `fullbody.jpg` - Image pour le full body sans matériel
- `legs.jpg` - Image pour le renforcement bas du corps
- `upperbody.jpg` - Image pour le renforcement haut du corps

## Format recommandé
- **Format** : JPG ou PNG
- **Taille** : 800x600 pixels minimum
- **Ratio** : 4:3 ou 16:9

## Notes
- Les images sont optionnelles. Si une image n'existe pas, un placeholder avec une icône sera affiché.
- Les vidéos YouTube peuvent être ajoutées via le champ `videoUrl` dans le code.
