# Vidéos d'exercices

Placez ici les vidéos des exercices au format MP4.

**Fichiers attendus :**
- squat.mp4
- pushup.mp4
- plank.mp4
- lunges.mp4
- burpee.mp4
- mountain_climber.mp4
- jumping_jacks.mp4
- high_knees.mp4
- deadlift.mp4
- pullup.mp4
- dips.mp4
- downward_dog.mp4
- warrior_pose.mp4

**Format recommandé :** MP4 (H.264 codec)
**Résolution recommandée :** 720p (1280x720) ou 1080p (1920x1080)
**Durée recommandée :** 30-60 secondes par exercice

**Note :** Les vidéos doivent être optimisées pour le mobile (poids raisonnable, < 5 Mo par vidéo si possible).

Si les fichiers n'existent pas, l'application affichera automatiquement un message d'information et un lecteur de remplacement.
