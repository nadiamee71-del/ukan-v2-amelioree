# Assets Transformation Projection™

## Structure des dossiers

Les images de démonstration pour les projections doivent être organisées comme suit :

```
assets/transformation/
├── 3m/
│   ├── month_0.png  (Photo actuelle)
│   ├── month_1.png  (M+1)
│   ├── month_2.png  (M+2)
│   └── month_3.png  (M+3)
├── 6m/
│   ├── month_0.png
│   ├── month_1.png
│   ├── ...
│   └── month_6.png
├── 9m/
│   ├── month_0.png
│   ├── month_1.png
│   ├── ...
│   └── month_9.png
└── 12m/
    ├── month_0.png
    ├── month_1.png
    ├── ...
    └── month_12.png
```

## Format des images

- **Format recommandé** : PNG avec fond transparent ou fond uni
- **Dimensions recommandées** : 400x600px (portrait) ou 600x400px (paysage)
- **Taille maximale** : 500 KB par image

## Placeholders

Si les images n'existent pas, l'application affichera automatiquement des placeholders avec le label du mois (ex. "M+3 DEMO").

## Note

Ces assets sont utilisés uniquement en mode démo. Dans la version finale, les images seront générées par IA/AR.
