## 📝 NOTES IMPORTANTES

### Format des fichiers
- **Extension** : `.png` (obligatoire)
- **Nom** : exactement `phase_Xmois.png` où X est le nombre de mois (0, 3, 6, 9, 12)
- **Casse** : respecter la casse exacte (minuscules)

### Dimensions recommandées
- **Format** : Portrait (400x600px) ou Paysage (600x400px)
- **Taille maximale** : 500 KB par image
- **Fond** : Transparent ou fond uni

### Si les images manquent
- L'application affichera automatiquement des **placeholders** avec le label de la phase (ex. "3 mois DEMO")
- L'application **ne plantera pas** si certaines images sont absentes
